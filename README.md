# dsh-smart-model

自动根据提示词复杂度切换 DeepSeek Harness 的模型与推理等级。输入框下方显示一个状态 chip, 点击可暂停/恢复自动切换。

## 分类规则

关键词打分, 同分取更严肃的档; 文本越长越偏向严肃档。

| 档位 | 模型 | 推理等级 | 典型输入 |
| --- | --- | --- | --- |
| trivial | DeepSeek-V4.1-Flash | 关 | 查时间/日期/天气/汇率、单位换算、拼写与大小写、排序 |
| light | DeepSeek-V4.1-Flash | 低 | 起名/标题/文案、润色、错别字、短信/邮件、翻译、一行命令、正则、简短总结 |
| standard | DeepSeek-V4-Pro | 高 | 写代码/调试/重构/架构、算法、数学、分析对比、论文/报告/方案、原理讲解 |
| deep | DeepSeek-V4-Pro | 最大 | 证明题/竞赛题、安全审计、密码学、法律合同、医学诊断、显式要求"仔细/严格/一步一步"的高难任务 |

## 行为

- 停止输入约 1 秒后才分类; 会话正在生成时不切换。
- 8 秒冷却, 防止来回抖动。
- 子代理会话、当前提供方目录里没有目标模型时自动跳过。
- 没命中任何关键词(闲聊、模糊请求)时保持当前选择不动。
- 以 `/` 开头的斜杠命令草稿不参与分类。
- 手动在模型菜单里选过之后, 以手动选择为准, 自动切换让位。

## 安装

```
dsh plugin add github:owner/dsh-smart-model
```

装完刷新页面或重启应用, 输入框下方会出现 `Flash · 关` 样式的 chip。

## 结构

- `index.js` — Host 端入口, 只负责把日志路径路由注册好, 不含模型逻辑
- `client.js` — Client 端全部逻辑(草稿订阅 + 分类 + 切换 + chip)
- `cordis.patch.yml` — 插件插入补丁
- `package.json` — 包清单, 声明 `dsh.bundle`, 前端入口 `dsh.client`
